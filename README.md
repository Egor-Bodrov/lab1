# Лабораторная работа 1. Первые программы на Python

## Состав
- hello.py — первые строки.
- profile.py — карточка студента.
- workload.py — учебная нагрузка.
- debug.py — исправление ошибок.
- swap.py — обмен значениями.
- variant.py — вариант 1 («Канцелярия»).

## Запуск
Python 3.13/3.14. В папке lab01:
    python hello.py
    python profile.py
    python workload.py
    python debug.py
    python swap.py
    python variant.py

## Проверки

### profile.py
- Возраст 17, часы 10.5 → 21; 42.00; 1.50. Факт: совпадает.
- Часы 0 → 0.00; 0.00. Факт: совпадает.
- Возраст 121 → сообщение об ошибке. Факт: совпадает.

### workload.py
- 3×90 и 2×45, доступно 10 ч → 270; 90; 360 мин = 6.00 ч; 4.00 ч; 24.00 ч. Факт: совпадает.
- 0 занятий по обоим → 0; 0; 0.00 ч. Факт: совпадает.
- Доступно 1 ч при нагрузке 6 ч → ошибка. Факт: совпадает.

### debug.py
- А: 5. Б: 18. В: 7.0. Факт: совпадает.

### swap.py
- А-101 и Б-202 → меняются. Одинаковые → остаются. Факт: совпадает.

### variant.py (вариант 8 — «Фотопечать»)
Пример: заказ «Фотопечать», заказчик «Анна Смирнова».
- Малые фотографии: 10 × 15.00 = 150.00
- Большие фотографии: 4 × 45.00 = 180.00
- Товары: 330.00
- Доставка: 20.00
- Итого: 350.00
- Количество: 14
- Внесено: 500.00 → сдача 150.00
Факт: совпадает.

## Пояснения
- **Строка и число:** `input()` возвращает `str`; для вычислений нужно `int()`/`float()`. `"2"+"3"` = «23», `2+3` = 5.
- **Порядок вычислений:** `*` и `/` раньше `+` и `-`; скобки меняют порядок.
- **Временная переменная:** в `swap.py` сохраняет одно значение, чтобы не потерять его при перезаписи.
- **Форматирование денег:** `:.2f` — два знака после точки.
